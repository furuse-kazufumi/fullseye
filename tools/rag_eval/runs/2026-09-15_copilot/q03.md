### **問3：円形部品の内径測定（エッジ〜寸法換算）**

**推奨 op 連鎖:**
```
gaussian → edges_sub_pix → create_metrology_model → 
add_metrology_object_circle_measure → align_metrology_model → apply_metrology_model
```

| 段階 | op 名 | 出力型 |
|------|------|------|
| 前処理 | `gaussian` | `image` |
| エッジ検出 | `edges_sub_pix` | `image`(サブピクセル) |
| モデル作成 | `create_metrology_model` | `metrologymodel` |
| 円追加 | `add_metrology_object_circle_measure` | `metrologymodel`(更新) |
| 位置合わせ | `align_metrology_model` | `metrologymodel`(位置決め) |
| 内径計測 | `apply_metrology_model` | `table`(直径 px単位) |

`apply_metrology_model` 出力の `params["radius"]` × 2 × (mm/px) = 内径(mm)

**根拠ファイル:** 
- `docs/ops/measure1d/model/add_metrology_object_circle_measure.md` (line 20-32)
- `docs/ops/measure1d/guides/subpixel_measuring.md` (line 39-50 flowchart)
- `docs/examples/poc_dimensional_inspection.py`

- 「寸法の換算」(ピクセル→物理単位)の手順が docs に記載なし

- `add_metrology_object_circle_measure` の `n=40`(サンプル点数)が半径依存なのに自動設定がない
