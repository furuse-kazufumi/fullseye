### **問2：偏光カメラ(4方向)から鏡面反射除去**

**使用 op:** `polarization_separate`

**呼び出し形式:**
```python
import fullseye as fs
diffuse, specular = fs.ledger.polarization_separate(
    images,  # (4, H, W) — 0°, 45°, 90°, 135° の画像
    angles_deg=(0.0, 45.0, 90.0, 135.0),
    max_violation_frac=0.0
)
```

出力: `diffuse`（拡散成分）、`specular`（鏡面反射成分、線形偏光部分）

**根拠ファイル:** `docs/ops/specular/polarization/polarization_separate.md` (line 21-46)

**迷った点:** 
- 金属上での使用可否：ドキュメント line 40-46 で「dielectric が前提で金属では信頼度が低い」と記載
- `max_violation_frac=0.0` はセンサノイズでも失敗 —— 実運用では上げるべき値の目安がない
