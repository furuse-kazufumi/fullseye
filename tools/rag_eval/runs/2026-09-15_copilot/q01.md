### **問1：金属平面のスクラッチ（幅 1-3 px）検出フロー**

**推奨 op 連鎖:**
```
gaussian → tophat → binary_threshold → gen_measure_arc → measure_pos → measure_pairs
```

| 段階 | op 名 | 用途 |
|------|------|------|
| 前処理 | `gaussian` | ノイズ除去 |
| 欠陥抽出 | `tophat` | 背景より小さく明るい傷を浮かせる |
| 二値化 | `binary_threshold` または `otsu` | スクラッチの領域を抽出 |
| 測定線生成 | `gen_measure_arc` | 傷に沿う測定弧を定義 |
| エッジ位置検出 | `measure_pos` | サブピクセル精度の幅を計測 |
| 幅算出 | `measure_pairs` | エッジ対から幅を算出 |

**根拠ファイル:** `docs/ops/2d/morphology/tophat.md` (line 36-40)、`docs/examples/poc_real_defect_floor.py`、`docs/ops/measure1d/guides/subpixel_measuring.md` (line 37-50)

**迷った点:** `tophat` の a パラメータ値が 3-9 px（スクラッチ幅に対応）か、ドキュメントに具体的な相対関係が記載されていない。
