# ViEW2026 会場の建物(国土交通省 Project PLATEAU、加工あり)

ViEW2026 の会場(横浜市西区みなとみらい 1 丁目、パシフィコ横浜)の建物 7 部位を、3D 都市モデルの
CityGML LOD2 から三角形メッシュにした小さな npz。小惑星イトカワ(約 535 m)など、大きさを実感しにくい物を
「会場の建物と並べる」作例の素材。作り方は `py -3.11 -I tools/gen_plateau_venue.py <原本の置き場>`
(原本は repo の外、信頼しないデータとして `-I` で読む)。

## 加工の内容(国土交通省・横浜市が作ったものではない)

- 7 部位だけを残した(下表)。属性は `measuredHeight` と建物 ID 等の汎用属性だけを `meta_json` に写した。
- 座標を EPSG:6697(緯度・経度・標高)から、地面の三角形の面積重心を原点とする接平面の局所座標
  (x 東・y 北・z 上、メートル、GRS80 の地心直交座標経由の厳密な変換)に移した。原点の緯度・経度・標高は `origin_llh`。
  標高と楕円体高の差(ジオイド高)は無視している(水平の相対誤差 6e-6)。
- 主題面(地面・壁・屋根)の多角形を三角形に分けた(穴は外周へ橋を架けて耳切り、向きは外向きのまま)。
  同じ座標の頂点を 1 つにまとめた。値の丸めはしていない(float64)。

## 門(`tools/gen_plateau_venue.py`、外れたら npz を書かない)

1. メッシュの高さ(屋根の最高点 − 地面の最低点)が `measuredHeight` と ±0.05 m で一致(実測の最大差 0.045 m。
   measuredHeight は 0.1 m 単位なので丸めの幅の半分)。
2. 原本のバイト列から正規表現で拾った LOD2 の座標を別の式(等距円筒)で測った幅と、メッシュの幅が ±0.05 m で一致
   (実測の最大差 0.005 m)。
3. 正規表現で拾い直した `measuredHeight` が読み手の値と完全一致。

建物の同定は座標で行った(PLATEAU のこの年度のデータには建物名が無い)。公開地図の施設名の位置と照合した:
国立大ホール・展示ホール・アネックスホール・ノースは外接箱の中心が 3 m 以内、ホテル棟と会議センターは両方の位置が
その部位の中に入る。ホテル棟と会議センターは PLATEAU では 1 つの部位で、分けていない。
