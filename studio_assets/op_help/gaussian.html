gaussian · smoothing · HALCON: gauss_filter

image → image

Convolves the image with an isotropic 2-D Gaussian kernel. It is the canonical linear low-pass filter: it suppresses high-frequency noise while preserving the overall structure, at the cost of blurring edges. Because a Gaussian is separable and scale-space optimal, it is the usual first step before gradient, edge or threshold operators.

Knobs

  • a — kernel sigma (blur radius). Small a = gentle denoise, large a = strong blur. Map ≈ σ = 0.3 + 2.7·a.
  • b — unused / reserved for this op.

Typical use

gaussian 0.4 0.5 → sobel_mag 0.5 0.5 → otsu 0.5 0.5
denoise, then take an edge magnitude, then binarise — a classic segmentation chain.

Provenance: separable Gaussian convolution (scipy.ndimage). Reimplemented from the published algorithm — see docs/PROVENANCE.md.
