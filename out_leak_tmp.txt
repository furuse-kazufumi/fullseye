埋設管の漏水を音で位置決めする —— 伝わる速さを間違えると、掘る場所がずれる
==============================================================================

2) 崖 —— SNR を掃く。★予測を先に置く
==============================================================================
  予測 A: 位置の散らばりは CRLB(Knapp-Carter 1976)に従う。
          σ_x = (c/2)·√{3(1+2ρ) / (8π² T (f2³-f1³) ρ²)}
          0 dB で 0.0066 m、-20 dB で 0.385 m。
  予測 B: 崖は CRLB の σ_τ が相関主ローブの半幅 1/(2 f_hi) = 625 µs に届く
          **SNR -20.1 dB** 付近。そこから下はピークの取り違えで、誤差は
          探索窓いっぱい(一様なら RMS 39.0 m)に飛ぶ。
  予測 C: 整数ピークは c/(2fs) = 0.076 m に量子化され、RMS は 0.0220 m を下回れない。
          ★ただしこれは**漏水位置を振ったときの** RMS。位置を 1 つに固定すると
          真の遅延の小数部も固定なので、量子化誤差は乱数ではなく**一定の偏り**になる。
  検算: 減衰を切った場面のビンごと CRLB 0.00660 m と平坦帯域の閉形式 0.00660 m は 0.05 % 差。
        減衰を入れると 0.00908 m へ悪化する(高域が先に痩せ、Fisher 情報は f² で効くため)。

     0.93 だったから**。誤差を「散らばり」と読むか「偏り」と読むかが、ここで分かれる。

3) 反射を入れる —— ★予想: PHAT が勝つ(白色化で直達ピークが立つ)
==============================================================================
  場面: センサの先 0.7 m / 1.1 m の継手で折り返す(往復 1.4 / 2.2 m)。
        遅れ差は 1.12 ms = 9.2 標本で、相関の主ローブ半幅 fs/(2 f_hi) = 5.1 標本と
        同じ桁 —— つまり**別のピークにならず、主ピークを歪ませる**。
  予想: 生の相関は主ピークが非対称になり、サブサンプルが反射側へ偏る。
        PHAT は振幅を白色化して実効帯域を広げるのでピークが尖り、
        反射に強いはず。ただし低 SNR では雑音しか無いビンも等しく
        持ち上げるので負けるはず。

     散らばりではないので、重み付けを変えても消えない。PHAT が白色化するのは
     相互スペクトルの**振幅** |X(f)| だが、遅延を運んでいるのは**位相** arg X(f) で、
     反射はその位相を歪める。PHAT は歪んだ位相をそのまま通す。
     対照群 継手 0.7/1.1 m       偏り -0.126 m
     対照群 左右を入替              偏り +0.126 m
     対照群 左右とも 0.7 m         偏り +0.000 m
     -> 左右を入れ替えると偏りの符号が反転し、対称にすると +0.000 m まで縮む。
        **偏りの向きは「どちら側の継手が遠いか」だけで決まる**(反射の強さではない)。

4) 対照群 —— (a) 音速が真値 (b) 10 % 間違える (c) 管種が変わる
==============================================================================
  ★予測: 音速の誤差は位置に**線形**に効く。Δx = (Δc/c)·(x - L/2)
          —— 中点では 0、端に行くほど大きい。相関の形は 1 ミリも変わらない。
   (a) 音速が真値 1250 m/s         c =  1250.0 m/s -> x =  77.998 m ( -0.002 m)
   (b) 音速を +10 % 誤る           c =  1375.0 m/s -> x =  79.798 m ( +1.798 m)
   (c) 音速を -10 % 誤る           c =  1125.0 m/s -> x =  76.199 m ( -1.801 m)
   予測(+10 %): +1.800 m / 実測 +1.798 m —— 差 0.0018 m

   ★中点の漏水(x = 60 m)は音速を ±15 % 間違えても 誤差 0.0007 m 以内。
     同じ誤りが x = 78 m では 2.701 m。**音速の誤りは中点からの距離に比例する**。

   (c) 管種が 60 m で変わる場合(鋳鉄 1250 m/s -> 樹脂 500 m/s)
      真の τ = -0.0000 ms / 推定 τ = -0.0019 ms(**相関はきれいに立っている**)
      鋳鉄の音速を仮定           c = 1250.0 -> x =  59.999 m (-18.001 m)
      樹脂の音速を仮定           c =  500.0 -> x =  60.000 m (-18.000 m)
      2 つの平均を仮定          c =  875.0 -> x =  59.999 m (-18.001 m)
      ★**どの音速を入れても 60 m 付近**。τ ≈ 0 なので x = (L + c·0)/2 = L/2。
         音速は掛け算の相手なので、**τ が 0 のときは何を掛けても直らない**。
         これはパラメータの誤りではなく**モデルの誤り**(区間で音速が違う)。

   管路全体に漏水を振ったときの最大の外し [m]: (a) 0.006 / (b) 5.400 / (c) 45.003
   ★(c) にはもう 1 段ある: 管種が違うと**真の遅延そのものが探索窓の外へ出る**。
     単一音速 1250 m/s が許す窓は |τ| <= L/c = 95.9 ms だが、この管路では x < 48 m と
     x > 99 m の漏水がその外にあり(掃引 37 点中 19 点)、相関器は窓の中の雑音を掴む。
     **「相関のピークが立った」ことは、真の遅延が窓に入っている証拠にならない。**

6) 道具の穴(この PoC を書いていて公開経路に無かったもの)
==============================================================================
  (a) 1-D の相互相関 / GCC(PHAT・ROTH・SCOT の重み)が無い。この PoC は 3-D 用の
      correlation_score を (1,1,N) に潰して使い、PHAT だけ numpy で書いた。
  (b) 遅延推定そのもの(time_delay_estimate)と、TDOA から位置を出す口が無い。
  (c) 群遅延 op が無い。transfer_function の位相を自分で unwrap して最小二乗で
      傾きを取った —— 位相の傾きは遅延そのものなので、族に入れる価値がある。
  (d) correlation_score は 3-D 専用で、1-D 信号は (1,1,N) に整形して渡すしかない。
      サブサンプルの相棒 refine_peak_newton も 27 近傍を要求するので 1-D では使えない。
