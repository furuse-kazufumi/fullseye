# GPU tier 分類 — 全 op の 4 段台帳

`tools/gpu_tier_rules.py` が機械可読索引 (`docs/OP_INDEX.json`) と正本名簿 (`fullseye/data/gpu_required.json`) から生成する。手書きしない。

## 4 段の定義

| tier | 意味 | 判定 |
|---|---|---|
| `required` | GPU 必須(CPU では実寸が非現実的) | 名簿 `gpu_required.json` に名指し |
| `suitable` | GPU 向き(密な画像・体積・信号・行列・動画) | in/out 型が密配列 |
| `partial` | 部分的(枚数方向のバッチだけ効く) | 領域・輪郭・ラベル・幾何・特徴・計測 |
| `none` | 恩恵なし | スカラー・表・I/O・文字列・ハンドル |

判定規則: 名簿にあれば `required`、無ければ `in_sort`/`out_sort` を型表で引き強い方 (`required` > `suitable` > `partial` > `none`)。

## GPU 対応率

指標 = `gpu_status=あり` の件数 ÷ (`required` + `suitable`) の件数(件数÷全体ではない)。現状値をそのまま書く(低くてよい)。

- gpu 経路あり: **173**
- `required` + `suitable`: **2231**
- **GPU 対応率 = 7.8%** (173 / 2231)

正直な内訳: gpu 経路を持つ op のうち 50 件は `partial`(領域モルフォロジ等)、0 件は `none` で、分母には入らない(分子にのみ計上)。
