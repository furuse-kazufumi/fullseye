# GPU 穴埋め 第 3 便 — HALCON OpenCL 48 件と required 名簿の採否 — 2026-11-02

`tools/gen_gpu_fill3_report.py` が実測ログ(`docs/perf/logs/fill3_*.json`)と実装台帳から生成する。数字を手で書かない。採用規則は parity 差 < 5e-3(torch CPU と GPU の両方)かつ実寸倍率 >= 5.0x。

- 計測機: NVIDIA GeForce RTX 5090 / torch 2.11.0+cu128
- HALCON 26.05 OpenCL 84 件のうち GPU 経路あり: **23 → 36**(対応あり 84 件中)
- 全 op の GPU 対応率: **108 件 → 173 件**、7.7% (173 / 2233)
- HALCON の 48 件の内訳: 採用 **13** / 不採用・測定不能 **35**
- required 名簿 48 件(GPU 経路なし)の内訳: 計測 17 件のうち採用 **15** / 計算核を書かなかった **31**
- 「HALCON より速い」等、測っていない比較は書かない。ここの倍率はすべて Fullseye の CPU 登録経路に対する比。
