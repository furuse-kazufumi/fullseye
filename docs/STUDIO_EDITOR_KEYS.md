# Studio のコードエディタ: 編集の操作とキー

Fullseye Studio のコードエディタ(Program 欄、Python エディタ)に後から取り付ける編集の操作の一覧です。
実装は `studio_editops.py`(計算。Qt なし)と `studio_editops_qt.py`(キー・マウス・描画)。
キーの割り当ての正本は `studio_editops.KEYMAP` の 1 つの表で、この文書・メニュー・当たりの検査はそこから引きます
(試験 `tests/test_studio_editops_2026_11_13.py` が、表のキーが全部この文書に載っている事を確かめます)。

操作の入口はキーだけではありません。エディタの右クリックのメニューに「矩形選択」「行の操作」「エディタの表示」が
あり、各項目の右にキーが出ます。「矩形選択の使い方…」は、本体を止めない小さな窓で下の要点を出します。

## 1. 矩形選択(箱形の選択)と複数のカーソル

| したい事 | キー・マウス |
|---|---|
| 箱で選ぶ | Alt + ドラッグ |
| カーソルからクリックした所までを箱にする | Shift + Alt + クリック |
| 箱を上へ広げる・縮める | `Shift+Alt+Up`(`Ctrl+Alt+Up` も同じ) |
| 箱を下へ広げる・縮める | `Shift+Alt+Down`(`Ctrl+Alt+Down` も同じ) |
| 箱を左へ広げる・縮める | `Shift+Alt+Left` |
| 箱を右へ広げる・縮める | `Shift+Alt+Right` |
| 上・下にカーソルを足す(幅 0 の箱) | `Ctrl+Alt+Up` / `Ctrl+Alt+Down` |
| 選んでいる語の次の一致を選択に足す | `Shift+Alt+.`(選びが無ければ、まずカーソルの語を選ぶ) |
| やめてカーソル 1 つへ戻る | `Esc`、または普通のクリック |

箱がある間に効く操作(どれも 1 回の操作 = 1 回の Undo):

| 操作 | 結果 |
|---|---|
| 文字を打つ | 全部の行の同じ桁に入る(選びがあれば置き換える)。幅 0 の箱 = 複数行のカーソル |
| Delete / Backspace | 選びを消す。幅 0 なら右 / 左の 1 文字。行をまたいでは消さない |
| Ctrl+C | 行ごとの選びを改行で繋いでコピー(全部が幅 0 なら、その行を丸ごと) |
| Ctrl+X | コピーして消す |
| Ctrl+V | 貼る物の行数 = 箱の行数なら行ごとに 1 つずつ。1 行なら全部の行に同じ物。それ以外は各カーソルに丸ごと貼り、カーソル 1 つへ戻る |
| Tab | 選びがあればその行を字下げ。幅 0 なら各カーソルの位置から次の 4 桁の位置まで空白 |
| Shift+Tab | その行の字下げを 1 段戻す |
| ← → Home End(Shift 付きも) | 全部のカーソルが動く(Shift で選びを伸ばす) |
| それ以外のキー(Enter、Ctrl+Z、↑↓ など) | 箱をやめて、そのキーの元の動作 |

### 桁の数え方(決めた事)

- 箱は**見た目の桁**で取ります。全角の文字(漢字・かな・全角英数)は 2 桁、半角カナは 1 桁、タブは次のタブ位置まで。
- 結合文字(濁点の結合形、アクセント)、異体字セレクタ、ZWJ で繋いだ絵文字、国旗は、前の文字とまとめて 1 つとして
  扱います。カーソルも箱の端も、その途中には入りません。絵文字(UTF-16 で 2 単位)でも位置はずれません。
- 箱の端が全角の真ん中やタブの途中に来たら、**近い方の境目**へ寄せます(同じ距離なら左)。VS Code と同じ規則です。
- **仮想の空白は作りません。** 行が箱の左端に届かない時、その行は箱に入りません(打っても空白で埋めません)。
  全部の行が届かない時だけ、全部の行の行末にカーソルを置きます。VS Code と同じです
  (Visual Studio は行末より右にも打てて空白で埋めますが、行末の空白が増えるので採りませんでした)。
- VS Code と違う所が 1 つあります。VS Code は箱の端が全角の真ん中に来た行を箱から外す事がありますが、
  こちらは外しません(日本語の行が黙って抜けるのを避けるため)。
- ※ ○ → α など、書体によって幅が変わる文字(Unicode の「曖昧幅」)は、**今の書体で実際に測って**決めます
  (日本語の書体では全角、欧文の書体では半角)。

### 既知の制約

- **書体**: 桁がそろって見えるのは、全角が半角のちょうど 2 倍の書体(BIZ UDGothic、MS ゴシックなど)です。
  Consolas は日本語の字を別の書体で代わりに描き、その幅は半角の 2 倍ではないので(12 pt で半角 8.8 px・全角 13.05 px)、
  日本語を含む行では箱の右端が行ごとに少しずれて見えます。選ばれる文字は桁の計算どおりで、ずれるのは見た目だけです。
- **IME**: 箱がある間の未確定の文字は 1 つのカーソルの所にだけ出て、確定した時に全部の行へ入ります(1 回の Undo)。
- **貼り付け**: 箱でコピーした物を、箱の無い所へ「箱の形のまま」貼る事は出来ません(行として貼られます)。
- **Enter**: 箱がある間の Enter は、箱をやめてから普通の改行になります(全部の行で改行はしません)。
- **補完の窓**が出ている間の Tab / Enter / Esc / ↑ / ↓ は窓の物です。先に Esc で窓を閉じてください。
- 右から左へ書く文字(アラビア文字など)の行は考えていません。
- ブレークポイントは行番号で持っているので、行を動かす・消す・複製する操作には付いて行きません(元からの制約)。

## 2. 行の操作

| したい事 | キー | 補足 |
|---|---|---|
| 行を複製 | `Ctrl+D` | 選んだ行(選びが無ければカーソルの行)。カーソルは複製の側へ移る |
| 行を上へ移動 | `Alt+Up` | 選んだ行をまとめて動かす |
| 行を下へ移動 | `Alt+Down` | |
| 行を削除 | `Ctrl+Shift+K` | |
| 行コメントの切り替え | `Ctrl+/` | Program 欄は元からある物(パイプラインは `* `、Python は `# `)。元から無いエディタにだけ足す |
| 字下げ | `Tab` | 複数行を選んでいればその行を字下げ。そうでなければ次の 4 桁の位置まで空白(タブ文字は入れない) |
| 字下げを戻す | `Shift+Tab` | |
| 対応する括弧へ移動 | `Ctrl+]` | もう一度押すと戻る。文字列とコメントの中の括弧は数えない |
| 行末の空白を削除 | (メニュー) | 全部の行。1 回の Undo |

## 3. 表示

| 物 | 既定 | 切り替え |
|---|---|---|
| 桁の目安の線(79 桁と 99 桁) | 出す | 右クリック ▸ エディタの表示 ▸ 79 桁と 99 桁の目安の線 |
| 保存の時に行末の空白を削除 | しない | 右クリック ▸ エディタの表示 ▸ 保存の時に行末の空白を削除 |
| 対応する括弧の強調 | 出す | (Python のモードは色分けの部品が元から出す。それ以外のエディタに足す) |
| 現在の行の強調 | 出す | (Program 欄は元から出す。元から無いエディタに足す) |

設定は Studio の設定(`editops/rulers`、`editops/trim_on_save`)に覚えます。

## 4. キーの当たり(決めた事と、機械で確かめている事)

| キー | Studio の既存の割り当て | 決めた事 |
|---|---|---|
| `Ctrl+D` | 段の一覧の「Duplicate stage(段の複製)」。段の一覧にフォーカスがある時だけ効く | エディタでは「行を複製」。同じ窓の中で Ctrl+D = 複製にそろえた(Visual Studio 2017 以降も同じ)。VS Code の Ctrl+D(次の一致を足す)は `Shift+Alt+.`(Visual Studio の割り当て)にした |
| `Ctrl+Shift+D` | Detach graphics window(窓全体) | 使わない |
| `Shift+Alt+Down` | なし | 矩形選択(Visual Studio)。VS Code の「行を下へ複製」には使わない |
| `Ctrl+/` | Program 欄の Comment / uncomment lines | Program 欄では元の物をそのまま使う |
| `Ctrl+F` `Ctrl+H` `F3` `Shift+F3` `Shift+F1` `Ctrl++` `Ctrl+-` `Ctrl+Return` `Ctrl+Space` | Program 欄・補完 | 使わない |
| `F5` `F6` `F9` `Ctrl+S` ほか窓全体のキー | 実行・保存など | 使わない |

確かめ方: `studio_editops_qt.check_conflicts(窓, エディタ)` が、窓の中の全部の `QAction` と `QShortcut` のキーと
その効く範囲を集め、こちらのキーと突き合わせます。試験
(`tests/test_studio_editops_qt_2026_11_13.py::test_no_key_of_ours_collides_with_any_shortcut_of_the_studio_window`)が、
本物の窓で当たりが 0 件である事と、わざと当てたら検出される事を確かめます。QPlainTextEdit の標準のキー
(プラットフォームごとに違う)との重なりは、X11 系の `Ctrl+D`(= Delete)だけを上書きとして認めています。

## 5. 取り付け方(開発者向け)

```python
import studio_editops as eo
import studio_editops_qt as eq

ops = eq.install(editor, tr=tr, settings=settings_getter)   # 既にある QPlainTextEdit へ後付け。2 度呼んでも 1 つ
ops.populate_menu(edit_menu)                                # メニューへ同じ入口(任意)
actions.update(ops.command_actions(window))                 # コマンドパレットへ(別名の語は eo.PALETTE_WORDS)
ops.before_save()                                           # 保存する側が、保存の直前に呼ぶ(設定が入なら行末の空白を落とす)
eq.uninstall(editor)                                        # 外すと元の振る舞いへ戻る
```

`install` を呼ばないエディタの振る舞いは 1 つも変わりません。
