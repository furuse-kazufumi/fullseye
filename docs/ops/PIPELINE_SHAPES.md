# 入出力の形とパイプラインの形

正本は `fullseye/data/OP_GRAPH.json` であり、`OP_SHAPES.json` はその問い合わせの雛形である。
直列と束の型による縮約は現在の実行器で組める。合流、分岐、状態つきの流れ、タイル実行には、
複数の型付き辺を実行する DAG 実行器が要る。型検査は各辺の全入力を検査し、進化の遺伝子は
節点 ID、辺 ID、入力ポートの接続を持つ非巡回グラフとして表す必要がある。

`fullseye.pipeline_shape(input_form, output_form)` は、形、指標、適するパターン、資源の目安、
現在組めるか、足りない実行機能を返す。実例は機械的に行と op を照合できたものだけを記載し、
それ以外は「実例なし」とする。
