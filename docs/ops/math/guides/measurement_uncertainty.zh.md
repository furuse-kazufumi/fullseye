# 测量不确定度与校准知识 —— 为了能主张“测得准”

fullseye 有测量用的 op（`measure3d` / `math_metrology` / `measure1d` / `contour`）。
但**测得的值能否说是有意义的**，是在 op 之外决定的。
本文不是 op 的说明，而是讲述用数字报告尺寸时所需的规约 —— 术语、校准、
不确定度的累加方法 —— 的教材。术语的定义以 VIM（JCGM 200:2012）为准，
不确定度的评定以 GUM（JCGM 100:2008）为准。

---

## 1. 严格使用术语（这里一混淆，讨论就无法成立）

VIM 的定义（附条款号，原文为英法对照）：

| 术语 | VIM | 定义（要点） |
| --- | --- | --- |
| **准确度**（measurement accuracy） | 2.13 | 测得值与**真值**之间的一致程度。**NOTE 1：它不是一个量，不用数值表示** |
| **正确度**（measurement trueness） | 2.14 | **无穷多次**重复测得值的**平均值**与参考值之间的一致程度。**与系统误差负相关，与随机误差无关** |
| **精密度**（measurement precision） | 2.15 | 在规定条件下重复测量所得**测得值之间**的一致程度。用标准偏差、方差、变异系数以数值表示 |
| 误差 | 2.16 | 测得值 − 参考值 |
| 系统误差 | 2.17 | 在重复测量中保持不变或按可预见方式变化的分量 |
| 随机误差 | 2.19 | 在重复测量中按不可预见方式变化的分量 |
| 重复性条件 | 2.20 | 相同程序、相同操作者、相同测量系统、相同条件、相同地点，在**短时间内**的重复 |
| 复现性条件 | 2.24 | 在**地点、操作者、测量系统不同**的条件下的重复 |
| 不确定度 | 2.26 | 表征赋予被测量之值的**分散性的非负参数** |
| 校准 | 2.39 | **分 2 步的操作**（§2） |
| 计量溯源性 | 2.41 | 通过**文件化的不间断的校准链**与参照对象相联系的特性 |

VIM 2.13 NOTE 2 点名告诫 ——
**不要把“accuracy”用作 trueness 的意思，也不要把“precision”用作 accuracy 的意思。**

这在实际工作中起作用的场景：

> 传感器目录上写着“**重复精度 0.4 µm**”。这是 precision（2.15），
> 既不是 accuracy 也不是 trueness。**同一个值反复出现，与这个值是否正确，
> 是两回事。** 要主张绝对尺寸，还需要另外的正确度及其依据（校准）。

（同样的话题见 `3d/guides/depth_sensors.md` §2.2–2.3。有的厂商会写正确度，
有的厂商只写精密度。）

### 不确定度的评定有 2 类（GUM）

* **A 类（Type A）** —— 根据测量序列的**统计分布**进行评定（以标准偏差表征）。
* **B 类（Type B）** —— 根据基于经验或其他信息的**概率密度函数**进行评定。

两者都先放到同一基准（标准不确定度）上再合成。
**扩展不确定度**是合成标准不确定度乘以**大于 1 的因子（包含因子 k）**所得，
k 由输出量的概率分布和所选的包含概率决定。惯例上多用 k = 2（约 95%），但
**不写 k 的扩展不确定度，其含义无法确定。**

## 2. 校准分为 2 步（常被误以为是 1 步）

VIM 2.39 明确写的是 2 个步骤：

1. 确立**测量标准提供的量值**（附不确定度）与**对应的示值**（附不确定度）之间的
   关系。
2. 利用该信息，确立**由示值获得测量结果的关系**。

也就是说 ——

> **“校准过了” = 知道了偏差，而不是修正好了。**
> 只有做到第 2 步（应用修正），测得值才会改变。

而且校准证书上**必定附有不确定度**。这个不确定度会**加到**自己测量的
不确定度上（VIM 2.41 的“链中每一环都对不确定度有贡献”）。
从原理上说，无法得到比标准器更好的不确定度。

## 3. 图像测量的不确定度预算（实际工作中的内容）

报告 1 个尺寸时，实际累加的项：

| 类别 | 项 | 备注 |
| --- | --- | --- |
| Type A | 同一视场、同一零件的**重复成像**的分散 | 首先测这个。10 次往往不够 |
| Type A | **重新放置工件**时的分散 | 与上一项分开测量。这一项往往占主导 |
| Type B | 校准靶标的**校准证书上的不确定度** | 链的上游 |
| Type B | **像素量化**（分辨力／√12 是均匀分布的标准偏差） | 是下限，而不是实际能力 |
| Type B | **镜头畸变的残差** | 根据校准后的重投影残差估计 |
| Type B | **温度漂移** | 测量预热前后的差。金属为 10⁻⁵/K 量级 |
| Type B | **照明的变动与边缘的偏置** | ★ 图像测量特有且属于最大一级 |

★ **在图像测量中，照明是最大一级的不确定度来源**，却常常只讨论机械和光学
就了事。照明一变，边缘的表观位置就会移动 —— 阈值法随阈值的位置而动，
亚像素法也会因亮度梯度的不对称而动。**对同一零件只改变照明来测量，
看数值是否变动**，是最快的确认方法。

---

## 4. 分辨力 ≠ 精密度 ≠ 准确度

* 即使 1 像素 = 10 µm，也不等于能以 10 µm 测量。
  边缘对比度高时，亚像素有时能做到 1/10，
  对比度低时，分散可能达到 1 像素以上。**像素尺寸是分辨力的参考，而不是精密度。**
* 反过来，**不要把显示位数与精密度混为一谈**。显示到 0.001 mm 并不意味着 0.001 mm 的准确度。
* `optical_budget` 返回的衍射极限（Airy 半径）和像素极限，
  是**再也分不开的上限**，而不是达成值。

---

## 5. Gage R&R（测量系统分析）

把测量的分散分为**重复性**（同一人、同一机器 = VIM 2.20 的条件）和
**复现性**（人、机器改变 = VIM 2.24 的条件），并分解为方差的方法。

惯例上，以相对于公差的 %GRR 判定为 **< 10% 可接受 / 10–30% 有条件接受 / > 30% 不可接受**
（这是 AIAG MSA 的惯例，并非国际标准规定了这些阈值）。

**在图像测量中人们往往以为不存在“人”，但实际上人的贡献依然存在**：
工件的放置方式、照明角度和强度的调整、阈值和参数的设定 —— 这些就是
“操作者”的方差。即使是自动设备，每次换型时也会引入。

## 6. 校准靶标（图像测量）

| 靶标 | 优点 | 陷阱 |
| --- | --- | --- |
| 棋盘格 | 角点定位好。对畸变估计有效 | 边缘的角点没有拍进来，畸变就无法确定。需要平面度 |
| 圆点阵列 | 能稳定求出重心 | **在投影下，“圆的重心”与“圆的中心”会偏离**（透视投影下的系统误差）。非远心时会起作用 |
| 圆环／同心圆 | 中心估计能力强 | 上述偏离依然存在 |

* **平面靶标只用 1 个位姿时，焦距与距离会发生退化。** 要变换位姿拍摄多张。
* 靶标本身需要**平面度与刻度的校准证书**（§2 的链）。
  打印出来的棋盘格不是校准器具。

## 7. fullseye 的现状（如实说明）

| 要素 | 现有的 | 欠缺的 |
| --- | --- | --- |
| 测量 | `measure3d` / `math_metrology` / `measure1d` / `contour` | **不返回不确定度**（只返回值） |
| 分辨力的上限 | `optical_budget`（Airy 半径、像素极限） | 可以作为 Type B 的一项使用 |
| 校准靶标 | 无 | 棋盘格／圆点阵列的**生成**（用 `optscene` 应当可以做出带真值的） |
| 不确定度预算 | 无 | 累加 Type A / Type B 并给出扩展不确定度的 op |
| Gage R&R | 无 | 方差分解的 op |

**如果接下来要做**：用 `optscene` 生成带真值的校准靶标，让校准 → 修正 →
残差这一闭环能够运转，是比较好的思路。合成数据**真值已知**，
因此可以验证校准流程本身的正确度（在实际设备上做不到）。

## 8. 诊断表 —— 从症状到原因

| 症状 | 首先怀疑 | 确认方法 |
| --- | --- | --- |
| 同一零件每次测量值都在变 | precision 的问题（Type A） | 不重新放置拍 30 次求 σ。再重新放置拍 30 次。**分开**比较 |
| 数值稳定但与其他测量仪器对不上 | trueness 的问题（系统误差） | 测量已校准的量规。差值恒定的话，用修正即可消除 |
| 上午和下午的值不同 | 温度漂移 | 改变预热时间进行测量。记录设备与房间的温度 |
| 调整照明后尺寸变了 | 边缘的偏置 | 只改变照明测量数值的变化量，计入预算的 Type B |
| 只有视场边缘尺寸对不上 | 畸变残差／校准时没有包含边缘的点 | **按画面位置**绘制重投影残差 |
| 圆心略微向外偏移 | 透视投影下圆的重心偏移 | 用远心镜头拍摄，或从圆的**轮廓**估计中心 |
| 显示以 0.1 µm 为步长却不能再现 | 把显示位数与精密度混为一谈 | 把分辨力、精密度、准确度分开重新书写 |
| 明明是自动设备，Gage R&R 却很差 | 换型、放置方式、参数设定带来的人为贡献 | 更换操作者重复测量，分离出复现性分量 |
