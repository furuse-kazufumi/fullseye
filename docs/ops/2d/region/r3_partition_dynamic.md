## 使い方

領域を、垂直方向の広がりが小さい列（くびれ）で水平に分割する（HALCON``partition_dynamic`` に相当）。

各列の前景画素数（密度）を数え、``0 < 密度 <= a * 最大密度`` を満たす列（くびれ）をゼロに潰して領域を分断する。``a``（0〜1）がくびれと判定するしきい値の割合。``b`` は未使用。密度が一様な領域には分断対象の列が無く、そのまま返る。
