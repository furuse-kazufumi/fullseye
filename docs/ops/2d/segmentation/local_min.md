# local_min — 2D `segmentation` op

- **データ種**: `image` → `region`
- **呼び出し**: `fullseye.apply(img, "local_min", a=0.5, b=0.5)` (2-D は 1 画像 + 2 スカラつまみ `a,b∈[0,1]` のモデル)
- **HALCON 相当**: `local_min`(意味・パラメータは HALCON リファレンスが参考になる)

## 使い方

局所極小点(領域極小)検出。``x`` が窓内の最小値(``_k(a)``)に一致し、
かつ ``x < 0.7-0.4*b`` を満たす画素を前景とする、``local_max`` の暗部版。
HALCON の ``local_min``（Detect all local minima in an image.）に相当。

``a`` が窓サイズを、``b`` が輝度の上限しきい値を振る。両方が使われる。
